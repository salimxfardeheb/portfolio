# Costumia – Costume Rental Management Platform

## Description

Costumia is a SaaS platform for costume rental shops in Algeria. It gives each shop a dashboard to manage stock by size, rentals, payments, and bookings, with automatic availability checks that prevent double bookings. Published items appear in a public directory filtered by wilaya, helping customers find the right costume at a nearby shop before renting it in store.
