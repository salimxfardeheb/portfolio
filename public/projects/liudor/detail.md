# LIUDOR – Event Venue Booking Platform

## Description

LIUDOR is a web platform for discovering, managing, and booking event venues. It connects customers with venue owners and simplifies the organization of weddings, conferences, parties, and other events through smart search, availability management, and online reservations.

## Project Duration

1-3 months

- Business Development
- Web Development
- SaaS Development
